# Maven

## Maven 的主要功能
1. 依赖管理
2. 构建管理


## Maven 的安装与配置
1. 通过 Homebrew 安装 Maven
2. 修改 Maven 的 `settings.xml` 文件


## 配置 IDEA 使用本地安装的 Maven
IDEA 自带 maven，但一般更常用的是使用本地的 Maven。

✅ 好习惯：每当创建一个新的 project，主动选择本地 Maven 作为构建工具。


## Maven 与 IDE 的关系
在日常开发中，
* 常见的开发工具可以在开发中用于代码提醒，比如 IDEA 和 Eclipse，
* Maven 则用于依赖管理和构建管理。

两者结合才是合理的用法。
